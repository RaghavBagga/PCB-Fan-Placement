Python scripts

FileWhat it does
simulation.pyCore solver: finite-volume build, cached conduction matrix, fan scan, metrics, self-test. Run python simulation.py.
Exact_checks.pyStencil, 1D fin, 2D convergence study with Richardson extrapolation, critical points. Needs sympy.
Gradient.pyAdjoint gradients of each chip's peak, KKT tie condition, minimum-norm descent.
Lagrange.pyRail constraint and fixed airflow budget, with multipliers checked by re-optimisation.
VectorCalculus.pyFlux, circulation, Divergence and Green checks, isotherm arc length, flow-line curvature.
Taylor.pyTaylor polynomials of the fan profile and board solves with the truncated fan.

Requirements: Python 3.9+, numpy, scipy, matplotlib, and sympy for the exact checks. Install with pip install numpy scipy matplotlib sympy.

Data

fan_scan.csvTmax, hottest point and hot area for all 2091 fan positions (2 mm steps, default fan).
summary.csvNo fan, best and worst positions.

Reproduce the main results

python simulation.py --test     # built-in self-test
python simulation.py 2          # scan, 2 mm steps (~11 s)
python Exact_checks.py          # validation figure
python Gradient.py              # adjoint gradients and optimum
python Lagrange.py              # constrained problems
python VectorCalculus.py        # flux and theorem checks
python Taylor.py                # Taylor analysis

The browser lab uses the same discretisation (2 mm cells, 5-point stencil, preconditioned conjugate gradients) as simulation.py, so the two agree; the lab's scan uses 4 mm steps for speed.

FM116 Advanced Calculus · Plaksha University. Instructor: Dr. Suresh Kumar. Raghav Bagga (model, equation, simulation and analysis).
An educational steady-state approximation, not a validated CFD or product-design tool. All parameters and the Gaussian fan profile are assumptions; nothing has been compared with measurements. Heat-transfer framework adapted from Zhang, Y. & Chen, L. (2024), A modeling method for thermal steady-state simulation of the four-layer printed circuit board, PLOS ONE 19(9), e0310237.
